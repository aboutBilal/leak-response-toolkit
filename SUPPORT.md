# Getting help

**Leaked a secret right now?** Rotate it first, then follow the [15-minute cheat sheet](CHEATSHEET.md) and the [incident runbook](docs/01-runbook.md). You do not need to wait for anyone.

| You want to | Go to |
|---|---|
| Ask how to use Spillkit, or share an idea | [Discussions](https://github.com/aboutBilal/spillkit/discussions) |
| Report something that does not work as documented | [Open a bug report](https://github.com/aboutBilal/spillkit/issues/new/choose) |
| Report a vulnerability in Spillkit | [Private security advisory](https://github.com/aboutBilal/spillkit/security/advisories/new), as described in the [security policy](SECURITY.md) |

Please never paste secret values, even revoked ones, into an issue or discussion. Types and counts are enough.

Spillkit is maintained by volunteers. There is no paid support and no response-time guarantee.
